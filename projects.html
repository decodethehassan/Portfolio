BLE Toolkit Android App

Project 02 · Android · Bluetooth Low Energy · GATT Client

A native Android BLE central/GATT-client toolkit for scanning, connecting to, inspecting, and interacting with Bluetooth Low Energy peripherals. Built as a practical engineering utility for embedded-device bring-up and BLE debugging, with workflows similar to professional BLE inspection tools.

Key Engineering Work
  • Implemented timed BLE scanning with RSSI sorting and search/filter support for device names, MAC addresses, service UUIDs, and manufacturer data.
  • Built GATT connection and service-discovery workflows with characteristic read/write operations, including HEX and UTF-8 payload formats.
  • Added notification and indication control through CCCD, MTU 247 requests, remote RSSI reads, and high connection-priority requests.
  • Created a live BLE operation log with text export/sharing plus HEX/Text and Bluetooth UUID conversion utilities.
  • Included an ESP32 BLE test peripheral example to support repeatable app and hardware validation.

Smart Medical Wristband Platform

Project 03 · nRF52840 Firmware · BLE · React Native · Biosignal Processing

An end-to-end research wearable platform combining custom nRF52840 firmware with a companion mobile application. The firmware acquires physiological and motion data, performs on-device signal processing and quality checks, stores raw and processed records in external flash, and exposes live and historical data over BLE. The mobile app connects to the wristband, visualizes physiological and developer-level sensor data, synchronizes device memory, exports raw data, and integrates Firebase-backed user and cloud workflows.

Key Engineering Work
  • Developed Zephyr-based nRF52840 firmware integrating the MAX30101 PPG sensor, LSM6DSO IMU, W25N01 external flash, optional ADS1113 ADC, and BLE telemetry services.
  • Implemented an on-device PPG processing pipeline with DC removal, filtering, motion-aware quality checks, peak detection, heart-rate estimation, and SpO2 candidate calculation.
  • Built BLE data paths for live sensor telemetry, processed Algorithm V0 results, stored-memory synchronization, and retrieval of raw high-rate sensor data.
  • Built the companion application with React Native, Expo, TypeScript, and react-native-ble-plx for wristband discovery, connection, live physiological views, and developer sensor inspection.
  • Added Firebase authentication and Firestore integration, resumable raw-memory synchronization, local .bin generation, and share/export workflows for research and offline analysis.

WiFi CSI Occupancy Detection & Smart Heater Control

Project 04 · ESP32-C6 · WiFi CSI · Edge ML · Smart-Home Integration

A privacy-focused ESP32-C6 sensing platform that turns ordinary 2.4 GHz WiFi channel data into room-occupancy events. The firmware processes CSI locally, fuses multiple motion and micro-motion features with an on-device logistic-regression model, suppresses transient false positives, and preserves occupancy during still/sleeping conditions using breathing-band Doppler evidence. The resulting OCCUPIED and EMPTY events provide the control boundary for integration with a Mill smart panel heater over its local REST API.

Key Engineering Work
  • Built the ESP-IDF occupancy pipeline around ESP32-C6 CSI receive callbacks, with local feature extraction and decision logic running without a cloud dependency.
  • Fused amplitude change, background residual, subcarrier decorrelation, breathing/micro-motion energy, spatial asymmetry, non-stationarity, and an embedded logistic-regression model into the occupancy score.
  • Implemented multi-layer false-positive suppression using sequential evidence accumulation, transient-spike rejection, and temporal guards before declaring occupancy.
  • Added breathing-band detection, persistent calibration in NVS, warm-start behavior, and night-mode logic for more reliable still-occupant handling.
  • Defined an event-driven heater-control interface with fail-safe OFF behavior and a local REST integration path for occupied/empty setpoint control; the repository identifies the full heater-control module and end-to-end validation as follow-on work.

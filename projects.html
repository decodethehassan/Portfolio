Embedded IoT DevOps Lab

Project 01 · CI/CD Automation · DevOps for Embedded IoT

A hands-on DevOps engineering lab that applies modern CI/CD practices to embedded and IoT development. The project demonstrates structured pipeline automation using Azure DevOps, reusable YAML components, automated build/deploy stages, and workflows designed to make firmware delivery more repeatable and maintainable.

Key Engineering Work
  • Designed multi-stage Azure DevOps YAML pipelines with distinct Build and Deploy stages.
  • Created parameterized step templates so pipeline logic can be reused across projects and repositories.
  • Implemented CI/CD workflow organization for embedded/IoT projects, including build validation and artifact-oriented delivery.
  • Added pipeline diagnostics for agent information, workspace paths, source directories, and job execution troubleshooting.
  • Practiced repository-driven DevOps workflows using Git, YAML, PowerShell/Linux tooling, and automation-first engineering.

BLE Toolkit Android App

Project 02 · Android · Bluetooth Low Energy · GATT Client

A native Android BLE central/GATT-client toolkit for scanning, connecting to, inspecting, and interacting with Bluetooth Low Energy peripherals. Built as a practical engineering utility for embedded-device bring-up and BLE debugging, with workflows similar to professional BLE inspection tools.

Key Engineering Work
  • Implemented timed BLE scanning with RSSI sorting and search/filter support for device names, MAC addresses, service UUIDs, and manufacturer data.
  • Built GATT connection and service-discovery workflows with characteristic read/write operations, including HEX and UTF-8 payload formats.
  • Added notification and indication control through CCCD, MTU 247 requests, remote RSSI reads, and high connection-priority requests.
  • Created a live BLE operation log with text export/sharing plus HEX/Text and Bluetooth UUID conversion utilities.
  • Included an ESP32 BLE test peripheral example to support repeatable app and hardware validation.
